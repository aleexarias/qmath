## [Unreleased]

### Added

- Initial package structure and core dependencies.
- Black-Scholes pricing, implied volatility, and greeks.
- Heston characteristic function with COS method pricing.
- Synthetic Heston chain generation.
- Forward and discount factor inference via put-call parity regression.
- Fengler constrained cubic-spline surface smoother.
- Breeden-Litzenberger risk-neutral density extraction.
- Static arbitrage checks (monotonicity, convexity, bounds).
- Density distance metrics (Wasserstein, L2, KS).
- Sphinx documentation with sphinx-gallery examples.
- Comprehensive test suite with property-based testing.
